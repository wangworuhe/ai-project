# 英语语法练习页结构化改造方案

## 目标

正文继续使用原书高清页面，保证版式和插图完整。练习标签逐步从“整页图片 + 坐标输入框”改为结构化网页：题目文字仍来自原书，图片从原练习页提取，输入框成为普通网页控件，适合键盘作答和不同屏幕宽度。

## 数据结构

每个 Unit 保存为独立数据文件，包含练习编号、原书说明、词库、图片和题目。题目使用稳定 ID，例如 `u1-1.1-2`；已有浏览器草稿继续使用这些 ID，迁移后不丢失。

每道题由以下字段组成：

- `id`：稳定题号和草稿键。
- `type`：`fill`、`match`、`rewrite`、`correct`、`dialogue` 或 `picture-fill`。
- `instruction`：原书练习说明，不改写。
- `segments`：按原句顺序排列的文字片段和可输入空位，支持一句多空。
- `options`：词库、配对选项等原书内容。
- `image`：从原练习页裁出的相关插图及替代文字。
- `source_page`：原 PDF 页码，便于复核。

标准答案以后单独保存在后端，不随练习清单发送到浏览器。本阶段只负责展示、作答和本地草稿。

## 页面组件

- `GrammarExerciseView`：练习页容器，按原书练习编号排列。
- `ExerciseBlock`：显示练习说明、词库和题组。
- `ExerciseItem`：根据题型渲染填空、配对、改写、判断修改、对话或看图填空。
- `ExerciseImage`：展示从原书提取的题目插图，保持图片与相关题目绑定。
- 草稿仍使用 `localStorage`，按版本、Unit 和稳定题目 ID 保存。

## 实施顺序

1. 先结构化 Unit 1，并逐题核对原书文字、图片、示例答案和空位数量。
2. 验证桌面端、窄屏、键盘 Tab 顺序和刷新恢复草稿。
3. 用相同数据结构迁移 Unit 2–5；每完成一个 Unit 才替换该 Unit 的整页复刻练习。
4. 五个 Unit 全部通过复核后，移除练习页坐标覆盖层；正文原书页不变。
5. 后续再接入标准答案、即时批改、错题本和导出，不在本轮实现。

## 验收标准

- 网页题干、说明、词库、题号和插图与原书一致，不新增或改写题目。
- 每个原书可作答空位都有对应网页控件，一句多空不会合并。
- 示例答案保持只读，不被误当成作答框。
- 切换标签、Unit 或刷新页面不会丢失已经输入的草稿。
- 不依赖绝对坐标，浏览器缩放和窄屏下仍可正常阅读与作答。
