# Grammar Unit 导入问题记录

本文件记录结构化导入中已经确认的问题、原因、修复和防回归方法。执行 `$grammar-unit-import` 或 `$grammar-unit-validate` 时必须先阅读；遇到新的、已经定位并解决的问题时追加记录，不删除历史。

## 记录格式

每条记录包含：日期、范围、现象、原因、修复、防回归检查、状态。只记录有证据支持的原因；尚未解决的问题标记为 `待解决`，不能写成既定结论。

## 已解决问题

### 2026-09-08：正文模块首句缺失

- 范围：Unit 1 正文 B、C、D 等模块。
- 现象：原书模块标签后的概括句未显示，正文直接从例句开始。
- 原因：PDF 缓存包含文字，但区块范围和网页渲染没有稳定保留经过审核的 `heading`。
- 修复：正文区块独立保存 `heading` 和 `heading_range`，导入时确认该标题确实存在于来源区块，统一阅读器固定渲染它。
- 防回归检查：逐模块比较标签、模块首句和后续正文；导入器必须拒绝来源区块中找不到审核标题的 Unit。
- 状态：已解决。

### 2026-09-08：Unit 1 练习 1.4 动词提示词消失

- 范围：练习 1.4 第 3–14 题，例如第 14 题 `(He / start)`。
- 现象：数据库题干含提示词，但网页只显示句子和答案框，提示动词消失。
- 原因：提示词被保存为 `cue` 片段，前端只渲染 `text` 和 `input`；同时数据包把部分 `cue` 排在句子后缀之后。
- 修复：统一渲染器支持 `cue`；修正片段顺序；提示词继承正文排版。
- 防回归检查：按顺序重组 `text`、`input`、`cue` 后必须与完整 `prompt` 一致；每个答案槽必须恰好出现一次；浏览器核对页面上所有括号提示。
- 状态：已解决。

### 2026-09-08：答案文本的 PDF 字体运行造成单词粘连

- 范围：完整 `Key to Exercises` 导入。
- 现象：少量答案出现 `orAmy`、`o’clockinthe morning` 等缺少空格的文本，以及 a/b 子答案重复题号。
- 原因：PDF 将视觉上一行文字拆为多个字体运行，直接拼接会丢失运行边界的空格；部分子答案沿用相同题号。
- 修复：答案解析器按几何和字体运行边界保留必要空格，并合并同题号的 a/b 子答案。
- 防回归检查：全量答案必须保持 145 个 Unit、566 个练习小节、3941 条记录；空答案、重复业务键和内容哈希异常均为 0；再次导入必须全部为 unchanged。
- 状态：已解决。

### 2026-09-08：多 Unit 批量处理容易掩盖单元级错误

- 范围：连续导入多个 Unit。
- 现象：如果先生成或导入全部 Unit 再统一检查，早期 Unit 的内容、图片或答案关联错误会传播到后续工作。
- 原因：缺少强制的单元级验收门。
- 修复：主流程一次只处理一个 Unit；每完成一个 Unit 必须调用 `$grammar-unit-validate`，通过后才能继续。
- 防回归检查：批次报告逐 Unit 给出 PASS；任一 Unit 失败立即停止，后续 Unit 保持未修改。
- 状态：流程规则已建立。
